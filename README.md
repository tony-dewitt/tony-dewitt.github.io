Design, motion, Ai and sound, built by one person across four disciplines.
Live: https://tony-dewitt.github.io
What's here
Four pillars, each opening in place from the landing page:
	
DESiGN	Brand identity, event graphics, packaging and campaign work — apparel brands, radio stations, venues
MOTiON	Broadcast spots, music video, 3D motion graphics and live visuals
Ai	AI-directed concept art, every generation documented — settings, failures, decisions
AUDiO	Two commercially released projects engineered end to end, plus original world audio
Plus ProjectMAG — an original IP sketched in 2010 and built out across sixteen years, from a painted city map to a venue standing in Unreal Engine 5.
Build
Plain static HTML, CSS and vanilla JavaScript. No framework, no build step, no dependencies.
Sections load their images only when opened, so the landing page stays light.
```
index.html     the entire site
img/           full-size section images
tiles/         panel preview tiles
video/         video assets
audio/         audio snippets
.nojekyll      serves the files as-is, no Jekyll processing
```
